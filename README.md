# Saravana Balaji Portfolio

A four-page website using only HTML and CSS. No JavaScript or build step.

Open index.html locally. Upload all files and the assets folder together to a static host.

Pages: index.html (Home), about.html (About, skills, experience and education), projects.html (Projects and client work), contact.html (Email and profile links).

Edit text and links in each HTML file. All pages share style.css; colours are defined at the top. Navigation and footer are repeated in each page, so update all four when changing them.

Replace assets/portrait.jpeg for your photo and assets/Saravana_Balaji_Resume.pdf for your resume. The included resume has your phone number removed.

Effects include page entrance fades, button lift, card hover, portrait straightening, active navigation underlines and progressive CSS scroll reveals on supported browsers. Scroll reveals are optional; other browsers show all content normally. Reduced-motion preferences disable animations.

Project descriptions use the supplied resume and confirmed status, rather than an independent code audit. FinSync is in progress. Email links open a mail application. No tracking or contact form is installed.
